# 视觉规则 · 沉静的生物工业

## 核心

精确骨架与柔化质感并存；低饱和底色中保留有限鲜活；形态有非人的距离，回应敏感而稳定。取意象的关系与张力，不复制雨、管道、植物、像素场景或迭代器舱室。

## 色彩

`mineral / 矿灰` 是原标本的明亮灰绿与温褐；`depth / 幽青` 是原标本的深青灰与旧金。两者颜色保留。
`stone / 岩灰` 替换暮紫，所有主题颜色的 RGB 三通道相等，包含线条、阴影、银灰生命色与强调色。区别依赖明度与材料层次，不靠色相。

JSON 与 CSS 是同一组值。不要另行用滤镜把整个页面去色以冒充岩灰；那会同时改变真实内容、状态图例或用户图像。动效验收中的独立着色场保留原参考参数，不跟随界面主题换色。

## 字体与形态

正文使用系统无衬线，生产正文建议 16px / 1.85；有叙事感的短标题可以使用衬线。等宽只用于短编号、时间与技术元信息。标本中小号英文是装饰标注，不是业务正文的默认字号。

对齐、间距与边界清楚。表面哑光、灰化、细密；材质允许轻微不均匀，输入和文字不可扭曲。细线优先于重框，局部切角与层积优先于满屏圆角卡片。不要给每个控件重复加切角。

## 材料

`--lui-grain` 控制极轻的程序化颗粒。纹理可关闭，不影响功能。不要用透明噪点盖住大段文字；生产长文保持干净阅读层。只在材料表面或品牌局部使用层积、明暗和有限阴影。

中央六片形态是形态／材质测试物，不是强制角色、Logo 或页面模板。生产界面无需放置它，仍应通过相同 token、边界与运动形成一致性。

## 静态与运动的分工

静态物体保留形体特征；所有新增状态反馈从 RIL 1.0.0 动效族中选用。旧标本的逐片旋转、光亮动画、鼠标 3D 倾斜、随机待机位移已移除。主标本以原版内容进场演示接触回应，不把所有效果塞进同一画面。

“活着”的感受不能用于伪造后台状态。在线、回忆、执行、完成与核验，必须有业务数据；风格标本只报告本地接触与演示状态。
