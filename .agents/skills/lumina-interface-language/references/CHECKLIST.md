# 接入验收

## 视觉

- 矿灰／幽青／岩灰都可切换；岩灰 token 全中性，无暮紫残留。
- 清晰正文、稳定编辑区、可关闭肌理；窄屏与 200% 放大不横向溢出。
- 没有照搬标本布局、中央形态或 CyberScientist 的研究工作台。

## 交互

- 键盘可进入并触发主要控件，focus-visible 可见；触屏不依赖悬停。
- 每个接入动作与源参考的参数、算法一致；像素切换需检查中间态，不能只看终态。
- 全部动作关闭与系统减少动作都能立即显示最终文字／状态；场景也停止。
- 场景可暂停，输入时暂停，离屏与隐藏时停止，换模式后只剩一个画布，卸载销毁。
- 不用装饰显示“正在思考”“已核验”等未经业务支持的状态。

## 交付

- `python verify.py` 通过；安装器重复安装无重复区块，升级前备份。
- 保留来源与许可；不打包字体文件或原作素材。
- 记录实际浏览器、视口、通过项与未测试项，不能把 WebGL 不可用写成测试通过。
