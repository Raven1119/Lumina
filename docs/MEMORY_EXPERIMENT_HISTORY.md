# Memory experiment history

## Old scheme: graph adapter route

The former Conversation Memory stack used MAGMA, grounded Formation,
FirstHit/reliable readers and several semantic-associative candidates. It was
replaced by the P8-derived Memory v1 organ because the task-card experiment
selected the lab's locally validated memory-side behavior for Chat. The former
code and tests remain recoverable from the local `archive/pre-memory-v1` tag;
this document does not make them active dependencies.
