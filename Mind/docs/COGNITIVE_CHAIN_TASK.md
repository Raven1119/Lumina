## Budget and decision rules (before any D6 real call)

Only deepseek-v4-pro, official Anthropic-compatible endpoint, thinking disabled,
temperature 0, 2000 output tokens per call. Preserve two cognitive steps, one
read, one repair and three physical calls per activity unless a later evidenced
process change is explicitly frozen with its cost before that stage.

- Diagnostic: two rule contexts, each with/without the erroneous prior item;
  four activities, maximum 12 calls. All other rule evidence, event opportunity,
  model configuration and allocated budget are held equal within each pair.
  Missing an explicit scope assessment is diagnostic uncertainty, not proof of
  correct reasoning. Removing a seeded error is a diagnostic intervention only.
- Development after diagnosis: maximum 24 calls across at most two frozen
  candidate passes. Each pass requires a documented implementation/process
  reason; never resample a failed cell to seek PASS. Use archived and renamed /
  reordered condition cases. No independent samples used for tuning.
- Independent acceptance: freeze three new cross-event cases after development,
  one real Execution workspace chain and two semantic controls. Maximum 27 Mind
  calls plus 12 Execution calls = 39. Run once, retain ordinary failures; stop
  immediately on mechanical authority, persistence or unknown-outcome failures.
- Overall maximum: 75 physical calls / 150000 allocated output tokens. All
  observed token fields and errors are results; no provider fallback.

NoChange, valid old citations and replacement IDs are legitimate. Correct
knowledge must remain represented; archiving everything, dropping every
discriminator, or emptying history cannot pass. Code validates shape, grounding,
versions and atomicity, never truth of natural-language reasoning. Whole-state
semantic review is explicit external measurement, never input to runtime Mind.

Final evidence must distinguish detected error, proposed/committed direction,
original-text delivery, actual later Execution behavior, owner feedback and
accepted final understanding. Execution may already know the correct algorithm;
task completion alone cannot establish independent Mind value.
