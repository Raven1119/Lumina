- **不重跑：** P8、P7 的回放、回答和盲评都读归档，不重新生成；保留集不运行。
- **摘要必须命中缓存：** P9 回放时允许新调用的用途为 dream、pattern、answer，不含 summary。摘要一旦未命中缓存，就停下并报告。
- **不修改：**
  - `core/` 和仓库其他目录；
  - `eval_set/scripts/`、`eval_set/gold/`、`eval_set/build.py`；
  - 已有的提示词文件。
- **旧预设（P8 及更早）的行为和缓存键不变。** 宽容解析只在 P9 和 R1 的重新解析中使用，不改变归档。
- **测试：** 新功能都要有离线测试，原有测试全部保持通过。
- **提交：** 所有改动做本地提交。推送只推 `docs/TASK_v5_2.md`、`docs/DESIGN_v5_2.md`、`docs/RESULTS_v5_2.md` 三个文档，每个阶段完成后推一次。推送后，用 `git ls-remote` 确认远端分支已经更新。
- `RESULTS_v5_2.md` 必须自成一体，仓库主人和 Claude 只看这份报告。

## 2. 阶段 2：实现

1. **痕迹层（§3）：**
   - Dream 处理新窗口时，把他说的话切句、编码、写入痕迹表；
   - 写入是确定的，窗口重试时不重复写；
   - 召回、渲染、整合、回答都不读痕迹。
2. **痕迹候选（§4）：**
   - 反复出现和常在同一天改在痕迹上找，日子下限为 3；
   - 去重、跳过、再次印证都按轮次集合比较。
3. **归纳（§5）：**
   - 使用 pattern_v3 提示词，痕迹组按 §5.1 渲染；
   - 按 §5.2 应用：校验 instances、按日子记 pattern 事件、按来源相交连 merge 边、文本去重、existing 的处理。
4. **两处修正（§6）：**
   - 宽容解析，只在 P9 中启用；
   - “用上”核对：两个字的公共子串只接受实体名或别名。
5. **预设 P9：** 参数见 §8，θₜ 取阶段 1 选定的值。
6. **离线测试至少覆盖：**
   - **痕迹写入：**
     - 只写他说的话；
     - 切句规则同 v5.1；
     - 同样的对话写出同样的表；
     - 窗口重试不重复写。
   - **痕迹不可见：** 召回、渲染、整合、回答在有痕迹和没有痕迹时结果逐字节相同。
   - **痕迹候选：**
     - 能从合成对话中找出三天都同时出现的两类话；
     - 只有两天时不成组；
     - 同一类不成对；
     - 权重门槛；
     - 同一句话在组里只出现一次；
     - 各项上限。
   - **跳过与再次印证：** 按规律的 sources 与组内轮次判定。
   - **pattern_v3 的应用：**
     - 轮次 instances 的校验：不属于本组、少于 2 句、不足 2 个逻辑日、缺失，各自被拒；
     - 按日子记 pattern 事件；
     - 没有来源相交的记忆时不连边；
     - 至多连 6 条；
     - existing 追加 sources；
     - 规律不进组，也永不出现自环。
   - **宽容解析：**
     - 值里夹着英文引号、原始换行、缺栏、键的顺序不同时都能解析；
     - 解析不出来时仍走重试和回退；
     - 回退时三栏内容不进入回复。
   - **“用上”核对：** 3 个字以上的子串通过；两个字的实体名通过；两个字的普通词（如“点到”）被拒。
   - **旧预设不变：** P8、P7 的召回、渲染和缓存键逐字节不变。
