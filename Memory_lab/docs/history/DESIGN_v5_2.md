# 设计 v5.2：隐性痕迹

2026-09-27。本文是 `DESIGN_v5_1.md` 的增量设计，只写这一版改什么、为什么这样改。未提到的部分沿用 P8。执行步骤见 `TASK_v5_2.md`。

## 1. 背景

### 1.1 v5.1 的结果

- **P8 成为新基线。** P8 没有达到 v5.1 §7.4 第 1 条的机制目标：植入联想的形成覆盖仍是 3/6。但它在同一模型下回答明显更好（J1 一致胜 12、一致负 3，p = .035），“变化”类的倒退已修好，规律卫生全部达标，记忆层持平或略好。仓库主人据此同意以 P8 作为新基线。
- **形成没有提升，原因在写入层。** D5 显示：
  - B12 的奶茶、B13 的河边骑车，一次都没有被写进任何记忆。整合提示词说“大多数闲聊不值得记”，模型照做了。
  - A13 的给妈妈打电话写进了 4 条记忆，但 P8 没有归纳出“开会那天打电话”。
- **在记忆分句上找“常在同一天”，噪音大。** dev_a 写出的 6 条里只有 m71（成像的晚上点麻辣烫）是真规律，其余是一件事的经过，或纯属巧合（m63：年糕好了和阿杰安静下来“常在同一天”）。只要求两天，太容易撞上巧合。
- **answer_v5 大多没有解析成功。** 28 条中有 22 条回退，“注意到”指标失效。回复本身没问题：J2 中 v5 对 v4 为 5:2。
- **“用上”仍有假命中。** 比如“几点到几点”命中了“点到”，“一点前睡觉”命中了“点前”。

### 1.2 根本矛盾

一件小事第一次出现时，确实不值得记；到第三次，它才构成值得知道的规律。可是等到第三次，前两次早已没有留下任何痕迹。只要写入层是“值得记才记”，规律就无从长出来。

## 2. 原则：统计学习

人对没有留意的小事，也会慢慢积累熟悉感。重复得够多，它才会浮现成“他好像每次交完稿都会点奶茶”这样的认识。这种学习不需要当时就把事情记成记忆。

据此加一层**隐性痕迹**：

- **痕迹不是记忆。** 它不进入记忆图，没有强度，不会被召回或渲染，整合看不到它，聊天时也用不到。
- **只有 Dream 写痕迹。** 痕迹在 Dream 处理新窗口时生成，只做本地计算，不调用模型。
- **只有归纳这一步读痕迹。** “反复出现”和“常在同一天”两类候选改在痕迹上找。找到后，把被选中的那几句原话作为依据交给归纳模型。
- **例外获准。** 归纳模型因此会读到当前窗口以外的旧原话，但只读候选选中的那几句。这是对“Dream 只处理新进 Cold 的内容”这条原则的明确例外，已经仓库主人同意。
- **淡忘不受影响。** 记忆里依然没有小事。小事只有反复出现、被写成规律之后，才进入记忆。

## 3. 痕迹层

### 3.1 写入

每次 Dream 处理新窗口时，对窗口内**他说的每一句话**（不含林素的话）：

1. 按 v5.1 §3.1 的规则切成分句：删日期，按标点切，短段合并，丢弃不足 4 个字的。
2. 用 bge-m3 编码。
3. 写入痕迹表：轮次 ID、分句序号、分句文本、原话全文、时间、逻辑日、向量。

同样的对话必须写出同样的痕迹表。Dream 解析失败、窗口被保留重试时，痕迹不重复写入。

### 3.2 不可见

召回、渲染、整合、回答，都不读痕迹表。这一条要有离线测试。

## 4. 候选（P9）

- **情形相似：** 不变，仍在记忆上找（v5.1 §3.2）。
- **反复出现、常在同一天：** 规则与 v5.1 §3.1 到 §3.3 相同，只做以下替换。
  - **单位：** 分句换成痕迹分句。一个分句的日子，就是它那句话所在的逻辑日。
  - **锚点：** 本次窗口的痕迹分句。
  - **N：** 截至当前，他说过话的逻辑日数。
  - **同一类：** 余弦 ≥ θₜ（`pattern_trace_kind_cos`），由 §7.1 的干跑选定。
  - **日子下限：**
    - 反复出现要求 \|KD(u)\| ≥ 3；
    - 常在同一天要求 \|C\| ≥ 3；
    - 两者都由 `pattern_trace_min_days` = 3 控制，用来挡掉“两天撞上”的巧合。
  - **权重门槛：** 常在同一天的权重门槛仍为 0.3。
  - **成员：**
    - 每个日子取与 u（以及 v）最像的痕迹分句所在的那句话；
    - 同一句话在组里只出现一次；
    - 反复出现至多 6 句；常在同一天至多 4 个日子、8 句。
- **去重与跳过：** 按 v5.1 §3.3 的顺序执行，比较对象从“记忆集合”换成“轮次集合”。
  - **跳过：** 已有某条规律的 sources 包含组内全部轮次。
  - **再次印证：** 已有某条规律的 sources 包含组内除本次窗口以外的全部轮次。这样的组保留，但排在后面。
- **上限：** 每种类型至多 2 组，合计至多 6 组。最终顺序同 v5.1。

在 P9 中，记忆分句上的“反复出现”和“常在同一天”不再使用。

## 5. 调用与应用

提示词为 `prompts/pattern_v3.md`，即 pattern_v2 加四处说明：

- 组里可以是记忆，也可以是他的原话；
- 原话单看大多不值一提，只有好几天反复出现才可能是规律；
- instances 可以是轮次 ID；
- “常在同一天”的组，instances 要列出两类事各自的依据。这样形成检查的“来源”一项才能对上两边。

### 5.1 渲染

- **痕迹组的每一行：** `- s04-t17｜3月5日｜他说：{原话全文}`，按时间排序。
- **线索：** 写法同 v5.1。「u」「v」取痕迹分句，截到前 24 个字。
- **`{{existing}}`：** 规则同 v5.1。对痕迹组，“有关联”指规律的 sources 与组内轮次相交。

### 5.2 应用（痕迹组）

- **`text`：**
  - **校验 instances：**
    - 只保留属于本组的轮次；
    - 剩下的须至少 2 句不同的话，覆盖至少 2 个逻辑日；
    - 不满足或缺少 instances 时，拒绝这一项并记录。
  - **新建规律：** 新建一条规律记忆，lineage 记为 `kind=pattern`、`origin=trace`。
    - sources 和出现时间取 instances；
    - salience 取模型给的值，限制在 1 到 3；
    - 实体为空。
  - **强度：** instances 覆盖的每个逻辑日，在当天最晚那句话的时间记一个 1.0 的 `pattern` 事件，不复制任何记忆的事件。反复被说到的事，因此天然就强。
  - **连边：** 找出 sources 与 instances 相交的非规律记忆，按相交轮次数降序、再按 ID 升序，取至多 6 条，各建一条权重 1.0 的 merge 边。
    - 一条都没有时不连边，规律单独存在，仍可经语义通道被召回。B12 就是这种情况：奶茶那几句话从没被写进记忆，但交稿那几天写了。
  - **文本去重：** 同 v5.1，余弦 ≥ 0.90 时转为 existing。
- **`existing`：**
  - 该 ID 必须是已有规律；
  - instances 按上面的规则校验，至少 1 句；
  - 追加 sources 和出现时间，在新轮次中最晚那句的时间记一个 1.0 的 touch 事件，并按上面的规则补 merge 边。
- **`none`：** 只记日志。
- **情形相似组的应用：** 不变（v5.1 §3.5）。
- **规律记忆的保护：** 仍按 v5.1 §3.6 执行，整合只能 touch 或 relate 规律。

## 6. 两处修正

### 6.1 answer_v5 的解析

提示词不变，只改解析：

1. 先按 v5.1 §5.2 的第 1 步解析。
2. 失败时，用正则找出 `"理解"`、`"借鉴"`、`"顺带"`、`"回复"` 四个键的位置。每个键的值，取到下一个键或结尾为止，再去掉首尾的 `"`、`,`、`}` 和空白。
3. 仍然取不到“回复”，才走原来的重试和回退。

这样，值里夹着英文引号的输出也能解析。开工前先确认失败的真实原因（§7.1 R1），如果不是这个原因，按实际原因调整，并写进报告。

### 6.2 “用上”的原话核对

v5.1 §6 第 3 条改为：公共子串 s 至少 3 个字；只有 2 个字时，s 必须是某个已知实体的名字或别名，例如“年糕”“阿杰”。常用词表不再使用。

### 7.4 采纳规则（P9 取代 P8）

以下四条必须全部满足：

1. **机制目标：** 形成覆盖（文本加来源）≥ min(6, P8 + 2)。P8 为 3/6，所以门槛是 5/6。
2. **记忆层不变差：**
   - 两集淡忘 +60、保留 +60 全部通过；
   - 每集的 cue 完全命中数、@3 命中数都 ≥ P8 − 1。
3. **回答不变差：**
   - J1 中一致负减一致胜 ≤ 4；
   - 说错条数 ≤ P8 的条数 + 1。
4. **卫生：**
   - 规律不进组，也不做 instances，自环为 0；
   - 召回、渲染、整合都不读痕迹，由离线测试保证。

## 9. 本版不处理

- **小事搭车。** 一次性小事如果被写进一条有意义的记忆（如“5 月 8 日歇了一晚没画，还提到楼下新开了个烤红薯摊”），会跟着那条记忆一起存活，无法单独淡忘。这需要改整合提示词，另开任务。
- **滚动摘要截断。** 桂花拿铁在 +60 天的回答里出现，入口是 Hot 和摘要。
- **规律在召回中的位置。**
- **人设。**
