### 偏差

- 仓库主人最新指令覆盖了任务卡要求的后续 DeepSeek 评测。只完成一轮历史校准；后续直接审阅，结论待独立复核。
- 模型有时给合法 JSON 加完整 Markdown 围栏，解析器只剥去完整外围；模型还常给出错误长度的评分数组，因此请求附加从 packet 算出的各 ID 所需数组长度，仍严格拒绝不合格输出。早先有效缓存按原评分规则复用。
