# 写入证据审阅口径

逐条阅读记忆正文及全部来源轮次原文。每一类只记录 yes/no；无法从所列来源确认时应标记编造，不以其他记忆补证。

1. **编造**：记忆断言没有来源依据，或把推测写成确定事实。
2. **说话人弄反**：把林素的发言、建议或判断记成他自己的，或反过来。
3. **概括过度**：只出现一次写成“常”、固定习惯，或把不同细节压成一种恒定细节。
4. **日期错误**：日期不符；有明确日历日期却只保留不稳定的相对时间，或把相对计划锚到错误绝对日期。
5. **人物混淆**：人名、性别、关系错误，或把同名不同人合并。

审阅者另记一句可核对的理由。五类标记可同时为 yes。统计分母为每个集合、每个写入版本导出的最终状态记忆数（至多 60 条）。

本次仓库主人要求由 Codex 自行评测；本口径用于直接审阅，不调用 DeepSeek 评审。
